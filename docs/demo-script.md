# DC.news Mantle — 2-Minute Demo Video Script

**Goal:** show the full submit → AI-grade → on-chain record cycle live, in under 2 minutes.

**Target:** Mantle Turing Test judges. They'll watch hundreds. Cut the intro. Get to value in <10 sec.

---

## Recording setup

- 1920x1080 screen recording
- Clear browser window with no personal tabs
- Terminal split alongside browser
- ~120 wpm narration pace
- Camera off (judges don't need a face)

## What NOT to do

- Don't explain DC's identity backstory (judges don't care)
- Don't claim things you can't show working live
- Don't use AI voiceover (judges can tell, weights against)
- Don't include music
- Don't go over 2 min — auto-fail in many tracks

## Optional polish

- Add subtle countdown overlay (top right) showing elapsed time so judges trust the timing
- Show wallet balance briefly (proves it's real, not a mock)
- Include the URL bar in every shot so they can verify domains
